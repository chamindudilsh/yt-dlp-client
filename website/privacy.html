Privacy Policy & Zero-Telemetry Pledge

Effective Date: October 1, 2026 • Applies to yt-dlp Client for Windows and ytdlpc.chamindu.lk

1. The Core Pledge: Zero Telemetry

yt-dlp Client for Windows is built with an absolute commitment to privacy. We do not collect, harvest, monitor, store, or sell any personal data, identifiers, IP addresses, search queries, or download histories.

The application contains zero tracking libraries, zero commercial analytics SDKs, zero advertising trackers, and zero background crash reporters pinging external developer servers.

2. 100% Local Application Processing

All media analysis, format conversions (MP3, FLAC, Opus), stream muxing, chapter splitting, and square album art cropping happen strictly on your personal computer using local child processes (`yt-dlp.exe`, `ffmpeg.exe`, `ffprobe.exe`).

  • Application Settings: Preferences such as custom output folders, format presets, and UI themes are saved locally on your device in your user configuration directory (`%APPDATA%` or application folder).
  • Download Archive: The archive tracking file (`--download-archive`) remains exclusively on your storage drive to prevent duplicate downloads across sessions.
  • Browser Cookies: When using the cookie extraction feature, cookies are read locally from your browser profile and passed strictly to the local `yt-dlp` executable. They are never transmitted to any external server.

3. Direct Third-Party Network Connections

When you initiate a search or download, the desktop application connects directly to the relevant third-party services without routing through any intermediary or proxy servers:

  • Media Streaming Platforms & Content Hosts: Direct HTTPS connections are established strictly between your device and the user-specified media host to retrieve audio/video streams and metadata. These requests are governed by each host's respective terms and policies.
  • GitHub Releases API: The application may query the public GitHub API (`api.github.com/repos/chamindudilsh/yt-dlp-client/releases/latest`) solely to notify you when an update is available. No user-identifying data is sent with this check.
  • SponsorBlock API (Optional): If you choose to enable SponsorBlock integration, the client queries public SponsorBlock API endpoints to retrieve segment timestamp data.

4. Website Hosting & Infrastructure

The documentation and landing website (`ytdlpc.chamindu.lk`) is statically hosted using GitHub Pages.

We do not use tracking cookies, tracking pixels, or third-party web analytics on this website. GitHub may record standard server access logs (such as visitor IP addresses, browser user agent, and timestamp) for diagnostic, security, and operational integrity purposes in accordance with the GitHub General Privacy Statement.

5. Open-Source Verification

You do not need to take our word for it. The complete source code for both the desktop client (Rust, Tauri v2, React 19) and this website is public and licensed under the MIT License.

You are welcome to inspect, audit, or compile the binaries yourself from the GitHub Repository.

6. Contact & Questions

If you have questions, feedback, or security inquiries regarding this policy or the application's source code, please open an issue on GitHub Issues or reach out through chamindu.lk.
